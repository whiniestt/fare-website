Use the Add to Discord button and follow Discord's authorization steps. Review the permissions requested before approving.

Join the Fare support server using the Support link on this page.

How do I find a command?

Open the command directory, choose a category or type a command name into the search box. The directory reflects the command list supplied for this website.
